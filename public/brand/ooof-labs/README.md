# ooof labs attribution kit

Copied from the ooof-labs identity master, version 1.0, 16 October 2026.

Use the full ooof labs logo for the app's maker credit. Keep the app's own name, icon, and identity. The compact of monogram is only for constrained square spaces.

- Light backgrounds: `ooof-labs-petrol.svg` or `ooof-labs-colour.svg`.
- Dark backgrounds: `ooof-labs-white.svg` or `ooof-labs-night.svg`.
- React Native: use the corresponding bundled 512px PNG with `resizeMode="contain"`.
- One-colour reproduction: `ooof-labs-black.svg`.
- Square artwork: `ooof-app-petrol.svg` and its 192/512px PNGs.

All SVG lettering is outlined. No font or external network request is needed. The ooof letters are custom geometry; labs is Instrument Sans Medium 500, with the SIL OFL license included here.

The full logo canvas is 573 × 173; preserve that ratio. Display it at least 140 CSS px wide. Its 28-unit clear space is already included. Do not crop, stretch, recolour, add shadows, or apply an app font to recreate the lettering. Pure white is #ffffff. Colour is petrol #153f42 with the middle o in copper #b24730; night uses mist #eef4ef and apricot #f0a67d.

The complete guide, additional sizes, and source geometry live in the sibling ooof-labs repository under public/brand and scripts/brand-geometry.mjs. These local copies intentionally contain only the app-ready assets; update them from that master rather than redrawing the mark.
